#  ZRUTE (Front End)
**ZRUTE** is an open-source technological solution created for tourists and new residents in the city of Trujillo, La Libertad, Peru. The main purpose of this application is to find the public urban transportation routes that are closest to the user’s current location, as well as identify which routes get closest to the user’s destination.
